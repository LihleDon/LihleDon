## What I build

Ingestion, transformation, and orchestration, in that order. I clean up data that has real problems (missing values, duplicates, cancelled records) and document exactly what I removed and why. Every project runs on real public data, not generated CSVs, because real data is the only kind that teaches you anything.

I work primarily in Python and SQL, orchestrate with Airflow, transform with dbt, and keep everything cloud-agnostic where I can so the skills transfer regardless of whether a team runs AWS, GCP, or Azure.
